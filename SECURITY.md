# Security

Prayer Focus Locker uses Accessibility only to read the package name of the app in the foreground.
It cannot read screen content. Camera frames are processed on the device and are never stored or sent.

## Reporting a vulnerability
Please open a GitHub Issue titled "Security" WITHOUT exploit details, and ask for a private way to share them.
I will reply as soon as I can.

## Note
This app is a self-discipline tool. A person with full access to a phone can always disable it.
