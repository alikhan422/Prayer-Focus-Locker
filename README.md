# Prayer Focus Locker

Locks selected apps at prayer time until you perform a live Ruku (bowing) scan with the camera.
Android 8.0+ only. Open source.

## Install
See [INSTALL.md](INSTALL.md). Download APKs from the [Releases](../../releases/latest) page.

## Privacy
- No internet permission. Camera frames are processed on-device and never saved or sent.
- Accessibility is used only to read which app is in the foreground (it cannot read screen content).

## Build from source
`./gradlew assembleDebug` (needs JDK 17+ and the Android SDK).

## Support the developer (optional)
See Settings -> Support in the app.
